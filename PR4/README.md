# ПР4 — Задание 1 «Времена года»

Класс `Season` описывает четыре времени года, хранит среднюю температуру и возвращает описание. Для лета метод `getDescription()` переопределён и возвращает «Теплое время года»; для остальных сезонов возвращается «Холодное время года».

Класс `Main` выводит сведения о выбранном любимом времени года, использует `switch` для печати фразы о нём и перебирает все константы перечисления.

Точка входа: `ru.mirea.pr4.Main`.
